# テンプレート取得確認手順

## 外部APIの確認方法

### 方法1: ブラウザで直接確認

1. ブラウザで以下のURLを開く：
   ```
   https://tsubasagit.github.io/AppNavi-asset/api/templates.json
   ```

2. JSONが正しく表示されることを確認
3. `templates`配列に5件のテンプレートが含まれていることを確認：
   - crm
   - google-calendar-group
   - daily-report
   - auto-integration
   - blank-page（新規）

### 方法2: AppNavi側で確認

1. AppNaviアプリケーションを起動
2. 開発者ツールのコンソールを開く（F12）
3. 「方針」タブを開く
4. 「外部サイトから更新」ボタンをクリック
5. コンソールに以下のログが表示されることを確認：

```
=== 外部サイトから取得したテンプレート ===
取得件数: 5件
1. ID: crm, 名前: 顧客管理（CRM）
2. ID: google-calendar-group, 名前: Googleカレンダーのグループ化
3. ID: daily-report, 名前: 日報チェック
4. ID: auto-integration, 名前: 自動連携
5. ID: blank-page, 名前: [テンプレート名]
```

## 期待される動作

### blank-pageテンプレートの処理

1. **取得**: 外部サイトから5件取得される
2. **変換**: `blank-page`は`iconMap`に含まれていないため、デフォルトの`Target`アイコンが使用される
3. **重複チェック**: ローカルテンプレートに`blank-page`がないため、新規テンプレートとして扱われる
4. **表示**: テンプレート一覧に表示される

## トラブルシューティング

### 問題1: 4件しか取得されない

**原因**: 
- 外部APIにまだ5件目が反映されていない
- キャッシュが古い

**解決方法**:
1. 外部サイト側でファイルを確認
2. GitHub Pagesのデプロイを確認
3. AppNavi側で「外部サイトから更新」ボタンをクリック（強制更新）

### 問題2: blank-pageが表示されない

**原因**:
- 重複チェックで除外されている
- 変換処理でエラーが発生している

**確認方法**:
コンソールログで以下を確認：
```
=== フィルタリング結果 ===
外部サイトテンプレート: 5件
ローカルテンプレート: 4件
重複除外後の外部サイトテンプレート: 1件
統合後の総テンプレート数: 5件
新規テンプレートID: blank-page
```

### 問題3: CORSエラー

**原因**: GitHub PagesでCORSヘッダーが設定されていない

**解決方法**:
- 開発環境: Viteプロキシを使用（既に実装済み）
- 本番環境: バックエンドプロキシサーバーを使用
