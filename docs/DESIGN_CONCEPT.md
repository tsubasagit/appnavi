# AppNavi 設計構想

## 概要

**中小企業経営者向けに、テンプレート（方針）を選ぶ、デザインができる、データを選ぶ、自由にカスタマイズできる。**

AppNaviは、IT知識の少ない中小企業経営者が、コードを書かずに業務アプリを作成できるNo-Codeプラットフォームです。

---

## ビジョン

**「データは個人に、プラットフォームはみんなに」**

---

## ターゲットユーザー

### メインターゲット：中小企業経営者

- IT投資予算がなく、Excelでの手作業に限界を感じている
- 高額なSaaS導入には踏み切れない
- データは手元に残したい（ベンダーロックインを避けたい）

### その他のターゲット

- 自治体職員（DX推進が必要だが予算制約が厳しい）
- NPO・非営利団体（コストを抑えたい）

---

## 3つのNO（特徴）

### ① No Code（コード不要・設計不要）

- **「作る」から「選ぶ」へ**：ドラッグ＆ドロップで画面を作る必要がない
- **テンプレートから選ぶ**：15種類以上の目的特化型テンプレートから選択
- **AIが自動生成**：「何のためのアプリか？」を入力するだけで、AIが最適な画面を提案

### ② No Cost（運用コストゼロ）

- **BYOD（Bring Your Own Data）**：データベースはユーザー自身のGoogleスプレッドシートやExcelファイル
- **サーバーレス**：FirebaseやGitHub Pages等の無料枠を活用
- **月額費用なし**：基本的な機能は無料で利用可能

### ③ No Fear（恐怖感の払拭）

- **データは手元に残る**：元のExcelファイルは変更されない
- **いつでも戻れる**：AppNaviの使用をやめてもデータは残る（ベンダーロックインなし）
- **安全な同期**：アプリ側からの操作は、元の重要なExcel数式を破壊しないよう安全に設計

## 4ステップのUXフロー

### Step 1: テンプレート（方針）を選ぶ

**機能**：目的特化型テンプレートから選択

**利用可能なテンプレート例**：
- 顧客管理（CRM）
- 在庫管理
- 日報・活動報告
- 予約管理
- 文書管理
- EC管理
- 資産管理
- 物流管理
- 経費精算
- 人事管理
- プロジェクト管理
- 品質管理
- 売上分析
- 予算管理
- 業績管理
- カスタム（ゼロから自由に設計）

**カスタムテンプレート選択時**：
- アプリの基本情報（アプリ名、概要）
- 現状の課題（Before）
- 解決策（After）
- 成果指標（KPI・目標）

これらの情報は、AIが以降の工程で判断基準として使用します。

---

### Step 2: デザインができる

**機能**：テーマエンジンによるデザインカスタマイズ

**主な機能**：
- **ページ管理**：複数ページの作成・編集
- **コンポーネント追加**：見出し、KPIグリッド、テーブル、グラフなど
- **プレビュー**：PC/モバイル表示の切り替え
- **プロパティ編集**：選択したコンポーネントの詳細設定

**特徴**：
- 細かい配置作業は不要
- プレビューを見ながらスイッチで表示/非表示を切り替えるだけ
- ドラッグ＆ドロップではなく、シンプルな選択式UI

---

### Step 3: データを選ぶ

**機能**：Excel/CSVアップロード、Googleスプレッドシート連携

**主な機能**：
- ファイルをドラッグするだけでデータ連携
- データ型（日付、金額など）の自動判定
- 複数のデータソースを管理

**安心設計**：
- 「元のファイルは変更されません」というメッセージを常時表示
- データはユーザーの手元（Google Drive/ローカルストレージ）に保存

---

### Step 4: 自由にカスタマイズできる

**機能**：グラフ自動生成、データ共有設定、運用・分析

**主な機能**：
- **グラフ自動生成**：Step 1で設定した「成果指標」に基づき、達成度を可視化するグラフが自動で配置
- **セキュリティ設定**：「社内限定（Googleログイン必須）」や「パスワード保護」をワンクリックで設定
- **ダッシュボード**：KPI追跡、目標管理、リアルタイム共有

**カスタマイズの自由度**：
- テンプレートをベースに、必要に応じて自由に機能を追加
- コンポーネントの追加・削除・編集が簡単
- データソースの変更も柔軟に対応

---

## 技術スタック

- **Frontend**: React 18 + TypeScript
- **Styling**: Tailwind CSS
- **Icons**: Lucide React
- **Routing**: React Router v6
- **Build Tool**: Vite
- **Infrastructure**: Firebase (Auth, Firestore, Hosting)
- **AI Engine**: Gemini API（コンテキスト理解、コード生成、データ分析）

## 中小企業DXの第一歩として

AppNaviは、ITベンダーに丸投げするのではなく、「自社で小さく始める」ことをDXの第一歩と定義します。

### 3ステップの変革支援

1. **デジタイゼーション（守りのデジタル化）**
   - 「紙と電話」や「個人のPCに眠るExcel」を、クラウド上の共有データに置き換え

2. **デジタライゼーション（攻めのデジタル化）**
   - デジタル化されたデータを活用し、業務プロセス自体を効率化・自動化

3. **デジタルトランスフォーメーション（DX - 経営の変革）**
   - データに基づいて経営判断を行い、ビジネスモデルや組織文化を変革

### Small Wins（小さな成功体験）の重視

いきなり全社規模の基幹システムを導入するのではなく、現場の小さな課題（日報、備品管理、アンケートなど）から成功体験を積み重ねます。「自分たちでもITで課題解決ができた」という自信（デジタル・エフィカシー）こそが、中小企業のDXを推進する最大のエンジンとなります。

---

## まとめ

AppNaviは、**「作る」から「選ぶ」へ**のパラダイムシフトを実現するプラットフォームです。

1. **テンプレート（方針）を選ぶ** → 15種類以上の目的特化型テンプレートから選択、またはカスタムで方針を設定
2. **デザインができる** → テーマエンジンで簡単にデザインをカスタマイズ
3. **データを選ぶ** → 既存のExcel/Googleスプレッドシートをそのまま活用
4. **自由にカスタマイズできる** → 必要に応じて機能を追加・編集

これらすべてが、**コード不要・コスト不要・恐怖感なし**で実現できます。
