# Firebase Cloud Functions コスト試算

## 概要

AppNaviのテンプレート取得機能でFirebase Cloud Functionsを使用する場合のコスト試算です。

## Firebase Cloud Functions の料金体系（2024年）

### 無料枠（Spark プラン）

- **呼び出し回数**: 月200万回まで無料
- **GB秒**: 月40万GB秒まで無料
- **GB時間**: 月125,000GB時間まで無料
- **ネットワーク送信**: 月5GBまで無料

### 従量課金（Blaze プラン）

無料枠を超えた場合：

- **呼び出し回数**: $0.40 / 100万回
- **GB秒**: $0.0000025 / GB秒
- **GB時間**: $0.0000025 / GB時間
- **ネットワーク送信**: $0.12 / GB

## AppNaviでの使用シナリオ

### 想定条件

- **テンプレート取得API**: 1回の呼び出しで約10KBのJSONを返す
- **実行時間**: 平均500ms（外部サイトへのリクエスト含む）
- **メモリ使用量**: 256MB
- **ネットワーク送信**: 10KB/リクエスト

### コスト計算

#### シナリオ1: 小規模（月100ユーザー、各ユーザーが週1回取得）

- **月間呼び出し回数**: 100ユーザー × 4回/月 = 400回
- **GB秒**: 400回 × 0.5秒 × 0.256GB = 51.2 GB秒
- **ネットワーク送信**: 400回 × 10KB = 4MB

**コスト**: **無料枠内** ✅

#### シナリオ2: 中規模（月1,000ユーザー、各ユーザーが週1回取得）

- **月間呼び出し回数**: 1,000ユーザー × 4回/月 = 4,000回
- **GB秒**: 4,000回 × 0.5秒 × 0.256GB = 512 GB秒
- **ネットワーク送信**: 4,000回 × 10KB = 40MB

**コスト**: **無料枠内** ✅

#### シナリオ3: 大規模（月10,000ユーザー、各ユーザーが週1回取得）

- **月間呼び出し回数**: 10,000ユーザー × 4回/月 = 40,000回
- **GB秒**: 40,000回 × 0.5秒 × 0.256GB = 5,120 GB秒
- **ネットワーク送信**: 40,000回 × 10KB = 400MB

**コスト**: **無料枠内** ✅

#### シナリオ4: 超大型（月100,000ユーザー、各ユーザーが週1回取得）

- **月間呼び出し回数**: 100,000ユーザー × 4回/月 = 400,000回
- **GB秒**: 400,000回 × 0.5秒 × 0.256GB = 51,200 GB秒
- **ネットワーク送信**: 400,000回 × 10KB = 4GB

**コスト計算**:
- 呼び出し回数: 400,000回（無料枠内）✅
- GB秒: 51,200 GB秒（無料枠内）✅
- ネットワーク送信: 4GB（無料枠内）✅

**コスト**: **無料枠内** ✅

#### シナリオ5: 極端なケース（月1,000,000ユーザー、各ユーザーが週1回取得）

- **月間呼び出し回数**: 1,000,000ユーザー × 4回/月 = 4,000,000回
- **GB秒**: 4,000,000回 × 0.5秒 × 0.256GB = 512,000 GB秒
- **ネットワーク送信**: 4,000,000回 × 10KB = 40GB

**コスト計算**:
- 呼び出し回数: 4,000,000回（無料枠200万回を超過）
  - 超過分: 2,000,000回
  - コスト: 2,000,000 / 1,000,000 × $0.40 = **$0.80**
- GB秒: 512,000 GB秒（無料枠40万GB秒を超過）
  - 超過分: 112,000 GB秒
  - コスト: 112,000 × $0.0000025 = **$0.28**
- ネットワーク送信: 40GB（無料枠5GBを超過）
  - 超過分: 35GB
  - コスト: 35 × $0.12 = **$4.20**

**合計コスト**: **約$5.28/月**（約800円/月）

## コスト最適化の方法

### 1. キャッシュ機能の追加

サーバー側でキャッシュを実装することで、外部サイトへのリクエスト回数を削減できます。

**効果**:
- 外部サイトへのリクエスト: 1回/時間 → 1回/24時間
- コスト削減: 約96%削減

### 2. クライアント側キャッシュの活用

既に実装済みのクライアント側キャッシュ（24時間）により、サーバーへのリクエスト回数が削減されます。

**効果**:
- ユーザーが「外部サイトから更新」ボタンを押す回数が減る
- サーバーへのリクエスト回数が削減

### 3. メモリ使用量の最適化

- デフォルトの256MBから128MBに削減可能
- GB秒のコストが約50%削減

### 4. 実行時間の最適化

- 外部サイトへのリクエストを最適化
- タイムアウト設定を適切に設定

## 実際のコスト試算（キャッシュあり）

### キャッシュ実装後のシナリオ

- **外部サイトへのリクエスト**: 1回/24時間（キャッシュ期間）
- **サーバーへのリクエスト**: ユーザーが「外部サイトから更新」ボタンを押した時のみ

#### 月100,000ユーザー、各ユーザーが月1回更新ボタンを押す場合

- **月間呼び出し回数**: 100,000回
- **GB秒**: 100,000回 × 0.5秒 × 0.256GB = 12,800 GB秒
- **ネットワーク送信**: 100,000回 × 10KB = 1GB

**コスト**: **無料枠内** ✅

#### 月1,000,000ユーザー、各ユーザーが月1回更新ボタンを押す場合

- **月間呼び出し回数**: 1,000,000回
- **GB秒**: 1,000,000回 × 0.5秒 × 0.256GB = 128,000 GB秒
- **ネットワーク送信**: 1,000,000回 × 10KB = 10GB

**コスト計算**:
- 呼び出し回数: 1,000,000回（無料枠内）✅
- GB秒: 128,000 GB秒（無料枠内）✅
- ネットワーク送信: 10GB（無料枠5GBを超過）
  - 超過分: 5GB
  - コスト: 5 × $0.12 = **$0.60**

**合計コスト**: **約$0.60/月**（約90円/月）

## 結論

### 小規模〜中規模（月10,000ユーザー以下）

- **コスト**: **完全無料** ✅
- Firebase Cloud Functionsの無料枠で十分

### 大規模（月100,000ユーザー以下）

- **コスト**: **ほぼ無料** ✅
- キャッシュ機能を実装すれば無料枠内

### 超大型（月1,000,000ユーザー以上）

- **コスト**: **月$1-10程度**（約150-1,500円/月）
- キャッシュ機能を実装すれば、月$1以下に抑えられる可能性が高い

### 推奨事項

1. **キャッシュ機能を実装**: サーバー側で24時間キャッシュを実装
2. **メモリ使用量を最適化**: 128MBに設定（十分な場合）
3. **監視**: Firebase Consoleで使用量を監視
