# ブラウザコンソールでテンプレートを作成する方法

## 実行方法

1. **AppNaviアプリケーションにログイン**（管理者権限が必要）
2. **ブラウザの開発者ツール（F12）を開く**
3. **コンソールタブを開く**
4. **`scripts/createTemplates-browser.js` の内容をコピー＆ペーストして実行**

## 注意事項

⚠️ **ファイルパスを入力するのではなく、ファイルの内容全体をコピー＆ペーストしてください**

### ❌ 間違った方法

```javascript
// これは実行できません
scripts/createTemplates-browser.js
```

### ✅ 正しい方法

1. `scripts/createTemplates-browser.js` ファイルを開く
2. **ファイルの内容全体をコピー**（Ctrl+A → Ctrl+C）
3. ブラウザコンソールに**貼り付け**（Ctrl+V）
4. Enterキーを押して実行

## 作成されるテンプレート

このスクリプトは以下の2つのテンプレートを作成します：

1. **CRMテンプレート** (`crm`)
   - 顧客管理、商談管理、活動履歴を一元管理
   - デフォルトで全ユーザーがインストール済み

2. **ブランクページテンプレート** (`blank-page`)
   - カスタマイズ可能な空のテンプレート
   - デフォルトで全ユーザーがインストール済み

## 実行結果

成功すると、以下のメッセージが表示されます：

```
📦 デフォルトテンプレートを作成中...
✓ テンプレート "crm" を作成しました
✓ テンプレート "blank-page" を作成しました
✅ デフォルトテンプレートの作成が完了しました！
- crm: 顧客管理（CRM）
- blank-page: ブランクページ
```

## エラーが発生した場合

### 権限エラー (`permission-denied`)

→ 管理者権限が必要です。Firebase Consoleでユーザーの`role`を`admin`に設定してください。

### Firestoreが初期化されていない

→ ページをリロードしてから再度実行してください。
