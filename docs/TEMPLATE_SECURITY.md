# テンプレートセキュリティガイド

## 概要

テンプレートは、すべてのユーザーが利用できるパブリックリソースです。そのため、テンプレートの作成・更新・削除は適切に制限する必要があります。

## セキュリティルール

### 読み取り権限

- **公開されているテンプレート** (`isPublic == true`): すべてのユーザーが読み取り可能
- **非公開テンプレート**: ベンダー（作成者）のみ読み取り可能

### 書き込み権限

以下のユーザーのみがテンプレートを作成・更新・削除可能です：

1. **管理者** (`role == 'admin'`): すべてのテンプレートを管理可能
2. **ベンダー** (`role == 'vendor'`): 自分のテンプレートのみ管理可能
   - 既存テンプレート: `vendorId == request.auth.uid` の場合のみ更新・削除可能
   - 新規作成: `vendorId == request.auth.uid` を設定したテンプレートのみ作成可能

### 開発環境

開発環境では、認証されているユーザーもテンプレートを作成・更新・削除可能です（開発用の緩和）。

**⚠️ 注意**: 本番環境では、この緩和は適用されません。

## テンプレート追加方法

### 本番環境での推奨方法

#### 方法1: Firebase Admin SDKを使用（推奨）

管理者がNode.jsスクリプトを使用してテンプレートを追加します：

```bash
# 管理者が実行
npm run create-templates
```

この方法では、Firebase Admin SDKを使用するため、セキュリティルールをバイパスできます。

#### 方法2: Firebase Consoleから管理者が追加

1. Firebase Consoleに管理者アカウントでログイン
2. Firestore Databaseを開く
3. `templates`コレクションを選択
4. ドキュメントを追加（JSONファイルから手動でコピー）

#### 方法3: 専用の管理画面から追加（将来実装）

管理者専用の管理画面を作成し、そこからテンプレートを追加できるようにします。

### 開発環境での方法

開発環境では、ブラウザコンソールから実行することも可能です：

1. AppNaviアプリケーションにログイン
2. 開発者ツール（F12）を開く
3. `scripts/create-templates-browser.js` の内容をコピー＆ペースト
4. 実行

**⚠️ 注意**: この方法は開発環境でのみ使用してください。

## セキュリティチェックリスト

- [ ] 本番環境では、テンプレートの書き込み権限が管理者とベンダーのみに制限されている
- [ ] 開発環境では、適切な警告が表示されている
- [ ] テンプレート作成時は、`vendorId`が適切に設定されている
- [ ] システムテンプレート（`vendorId`がない場合）は管理者のみが管理可能
- [ ] テンプレートの読み取り権限が適切に設定されている（公開テンプレートは全員が読み取り可能）

## トラブルシューティング

### エラー: "Missing or insufficient permissions"

テンプレートの追加に失敗する場合：

1. **管理者アカウントでログインしているか確認**
   - ユーザーの`role`フィールドが`'admin'`であることを確認
2. **ベンダーの場合**
   - `vendorId`が自分のユーザーIDと一致していることを確認
3. **開発環境の場合**
   - 認証されていることを確認（テストユーザーの場合は不要）

### エラー: "Firebaseインスタンスが見つかりません"

ブラウザコンソールから実行する場合：

1. ページをリロードしてから再度実行
2. AppNaviアプリケーションにログインしていることを確認
3. 開発サーバーが起動していることを確認
